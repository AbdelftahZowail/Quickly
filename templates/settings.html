Most configuration values such as email provider, API keys, SMTP settings, Google OAuth credentials, etc. are still supplied via environment variables or a `.env` file. These are read when the process starts and are not editable from this UI.

The runtime preferences you can adjust here are:

  • Scheduling strategy (priority vs. round-robin)
  • Dark / light mode toggle (client-side only)
  • Test mode (emails are redirected/simulated; use this instead of the old `TEST_MODE` env variable)

Please refer to README.md for the current behaviour of the settings page; the TEST_MODE environment variable only affects the very first startup and can safely be removed from your `.env` file.
