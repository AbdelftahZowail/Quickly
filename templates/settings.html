Setup Instructions — Google Cloud Console

Follow these steps to get your GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET.

Step 1 — Create a Google Cloud project

  1. Go to Google Cloud Console
  2. Click the project dropdown at the top → New Project
  3. Name it (e.g. "Campaign Engine") and click Create

Step 2 — Enable the Gmail API

  1. In your new project, go to APIs & Services → Library
  2. Search for "Gmail API"
  3. Click it and press Enable

Step 3 — Configure OAuth consent screen

  1. Go to APIs & Services → OAuth consent screen
  2. Choose External (or Internal if using Google Workspace)
  3. Fill in the required fields (App name, User support email, Developer email)
  4. On the Scopes page, click Add or Remove Scopes and add:
    • https://www.googleapis.com/auth/gmail.send
    • https://www.googleapis.com/auth/userinfo.email
  5. On the Test users page, add the Gmail addresses you want to connect
  6. Click Save and Continue through all steps

Step 4 — Create OAuth credentials

  1. Go to APIs & Services → Credentials
  2. Click + Create Credentials → OAuth client ID
  3. Application type: Web application
  4. Name: anything (e.g. "Campaign Engine")
  5. Under Authorized redirect URIs, add:
  6. Click Create
  7. Copy the Client ID and Client Secret

Step 5 — Save your credentials

Go to the Accounts page to save your Client ID and Client Secret, then return here to connect your Gmail inbox.

Note: While your app is in "Testing" mode in Google Cloud, only the test users you added can connect. To allow any Google account, submit for verification (Google will review your app). For personal / internal use, "Testing" mode is fine.
