Up and running in under 5 minutes.

Fastest

Railway

No server to manage, automatic HTTPS, free tier available.

# Deploy a Docker image on Railway
azowail/quickly:latest

# Add PostgreSQL plugin
# Railway injects DATABASE_URL
# Set env vars → deploy
Self-Hosted

VPS (Docker)

Any Linux VPS with Docker Compose. Caddy handles TLS.

docker volume create quickly_pgdata
mkdir quickly && cd quickly
curl -LO https://github.com/azowail/quickly/releases/latest/download/docker-compose.yml
curl -LO https://github.com/azowail/quickly/releases/latest/download/.env.example

# edit .env → set CADDY_HOST, BASE_URL, SECRET_KEY

docker compose up -d
Development

Local Dev

For contributing or exploring the codebase up close.

git clone https://github.com/azowail/quickly.git
cd quickly

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

uvicorn app.main:app --reload    # API :8000

# second terminal:
cd frontend && npm install && npm run dev # UI :5173
