# Contributing to Quickly

Thanks for wanting to help! The full contributor guide lives in
**[docs/CONTRIBUTORS.md](docs/CONTRIBUTORS.md)** — local setup, project structure,
tests, code style, and PR guidelines.

---

## Sign the CLA before your first pull request

Quickly asks every contributor to accept a short
[Contributor License Agreement](CLA.md) once. It takes a single comment.

- **You keep the copyright to your work** — it's a license, not a copyright
  assignment.
- **Your contributions stay open** — they remain available to everyone under the
  MIT License.
- **It exists for one reason:** so the project can change or dual-license its terms
  in future (say, adding a commercial edition) without having to track down every
  past contributor for permission. Without it, one unreachable contributor could
  permanently block a license change.

**How to sign:** just open your pull request. The CLA Assistant bot will comment on
it. Reply with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

That's it — one comment, once, and it covers all your future contributions.
See [CLA.md](CLA.md) for the full text.

## Quick start

```bash
git clone https://github.com/<your-username>/Quickly.git
cd Quickly
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Then follow [docs/CONTRIBUTORS.md](docs/CONTRIBUTORS.md) for the frontend, the
database, and running the app locally.
